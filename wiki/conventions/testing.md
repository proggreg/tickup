# Testing Conventions

## Two test suites

| Suite | Tool | Location | Command |
|-------|------|----------|---------|
| E2e | Playwright | `e2e/` | `pnpm e2e` |
| Unit + MCP integration | Vitest | `test/unit/` | `pnpm test:coverage` |

## E2e tests

### Setup
- Import `test` and `expect` from `e2e/fixtures/index.ts` (not `@playwright/test`)
- `listAPI` fixture: typed wrapper for creating/deleting lists via API in `beforeEach`
- Auth state from `user.json` (generated by `e2e/global.setup.ts`)
- Credentials: `testuser@example.com` / `password`
- Dev server starts automatically via `webServer` config with `NODE_ENV=test pnpm dev`

### Selectors
- Prefer `getByRole`, `getByTestId`, `.v-list-item`
- Avoid broad `div` locators
- `data-testid` attributes on: `new-todo-input`, `list-select`, `create-todo-button`, `dialog-title`, `dialog-close`, `todo-title`
- Select list rows by id, not raw name (avoids display name fragility)

### Running single test
```bash
npx playwright test e2e/todos/new/select-list-test.spec.ts
```

### API tests only
```bash
pnpm test:api
```

## Unit + MCP integration tests

### MCP tests
- Live in `test/unit/mcp/`
- Each file tests one MCP tool (e.g. `create-todo.test.ts`)
- Make real HTTP calls to `localhost:3000/mcp`
- Require running dev server for coverage

### Fixtures
- `test/unit/fixtures/api.ts` — API test helpers
- `test/unit/fixtures/mcp.ts` — MCP test helpers

### Coverage workflow

| Command | What it does |
|---------|-------------|
| `pnpm test:coverage` | Vitest with v8 coverage (client-side only) |
| `pnpm coverage` | Full: starts server with `NODE_V8_COVERAGE`, runs tests, merges with c8 |

Coverage output:
- `.nyc_output/` — v8 coverage from running server
- `.coverage/` — final merged HTML/JSON/text reports

Config: `.c8rc.json`, `scripts/coverage.sh`

## Bug fix convention

Every bug fix in an MCP tool must have a regression test on that tool's test branch. Each MCP tool has a paired task in tickup: `write-a-test-for-the-'<tool-name>'-mcp-tool`. Bug fix and test ship together.
